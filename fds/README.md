# FDS Modelling Folder

This folder contains all FDS-related files and models.

## spyro_cone_demo_3

A model replicating cone calorimeter tests to compare test data with FDS results.

## model_1

A compartment fire model with a timber slab as the material.

## model_1_spyro

A compartment fire model identical to `model_1`, except that it uses `spyro` for constructing the timber slab.
